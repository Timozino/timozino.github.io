# Folorunso Timson — Portfolio

A responsive, dark editorial-style software engineering portfolio built with Next.js App Router, TypeScript, Tailwind CSS 4, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize
- Main content, project descriptions, experience and credentials: `app/page.tsx`
- Visual system and responsive styles: `app/globals.css`
- Profile image: `public/timson.png`
- Résumé download: `public/F-TimsonCV.pdf`

## Before publishing
1. Add GitHub and any public project/demo links when ready.
2. Add screenshots or short product videos for Code Slate, Lagido and NexerCast.
3. Confirm exact project release status and public case-study details.
4. Replace or supplement the CV portrait if you have a higher-resolution professional headshot.
5. Deploy to Vercel or another Next.js host and connect your domain.

The portfolio intentionally does not invent GitHub links, project URLs, performance metrics or unverified claims.
